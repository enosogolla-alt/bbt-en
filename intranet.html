Intranet
A private, internal network  •  Accessible only within an organisation  •  Uses Internet technologies

An intranet is a private, restricted network that belongs exclusively to an organisation. It uses the same technologies as the Internet — HTTP, HTML, and TCP/IP — but is completely closed off from the public. Only authorised employees or members can access it, typically from within the organisation's physical premises or via a secure VPN.

◆ An intranet connects internal departments and employees on a secure, private network isolated from the public Internet
Key Features of an Intranet
01
Private and Access-Controlled

Access requires authentication — username and password or network credentials. Unauthorised users cannot access intranet resources from outside.

02
Uses Internet Technologies

Intranets are built using the same protocols as the Internet — HTTP, TCP/IP, and HTML — making them familiar and easy to maintain.

03
Internal Communication Hub

Employees use the intranet to share documents, announcements, policies, HR forms, internal news, and collaborate on projects securely.

04
Protected by Firewalls

A firewall separates the intranet from the public Internet, ensuring that internal data stays inside and external threats stay out.

Role in Computer & Internet Technology

Intranets play a vital role in modern organisations by providing a secure, centralised platform for internal communication and collaboration. They reduce reliance on email, improve document management, and give employees a single place to access company resources. Hospitals, universities, government agencies, and corporations all rely heavily on intranets to operate efficiently.

🔒
Intranet vs Internet: The Internet is a global public network open to everyone. An intranet is a private network using the same technology but restricted to one organisation's authorised users only.
