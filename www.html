01  /  Core Concept
World Wide Web
Abbreviated: WWW  •  Invented: 1989  •  Public Release: 1991

The World Wide Web is a vast, interconnected system of documents and digital resources linked by hyperlinks and URLs, accessible through the Internet via a web browser. It is the single most transformative information system ever built — powering everything from search engines to online banking to streaming platforms.

◆ Global network of interconnected web servers and clients communicating via HTTP
How It Works
01
You type a URL into your browser

The browser interprets the address and prepares an HTTP request to send to the correct server.

02
DNS resolves the domain to an IP address

The domain name (e.g. google.com) is translated into a numeric IP address so the request is routed correctly.

03
The web server receives and responds

The server processes the request and returns the HTML, CSS, and JavaScript files that make up the page.

04
Your browser renders the page

The browser assembles all files and displays the fully formatted webpage on your screen.

Role in Computer & Internet Technology

The Web sits on top of the Internet's infrastructure and uses it as a transport layer. Without the Web, the Internet would exist purely as a network of raw data pipes — useful only to engineers. The WWW gave it a human-friendly face through pages, links, and media, enabling mass adoption across every sector of society and industry.

💡
Key distinction: The Internet is the global network infrastructure. The World Wide Web is a service that runs on top of it — just like email or FTP. They are not the same thing.
