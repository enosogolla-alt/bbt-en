World Wide Web
Also known as: the Web, WWW, W3
Overview

The World Wide Web is an information system that enables documents, images, videos, and other resources to be accessed over the Internet through a web browser. It was invented by British scientist Tim Berners-Lee in 1989 while working at CERN, and became publicly available in 1991. The Web is not the same as the Internet — rather, it is one of many services that runs on top of the Internet infrastructure.

How It Works

The Web operates through three core technologies: HTML (HyperText Markup Language) which structures content, URLs (Uniform Resource Locators) which provide unique addresses for every resource, and HTTP (HyperText Transfer Protocol) which governs how data is requested and delivered between a browser and a server. When you type a web address, your browser sends an HTTP request to a web server, which then returns the requested page for your browser to display.

Role in Computer & Internet Technology

The World Wide Web transformed how humans access, share, and communicate information. It enabled the rise of e-commerce, online education, social media, cloud computing, and virtually every modern digital service. It democratised information by making it accessible to anyone with an internet connection and a browser, regardless of location or technical expertise.
