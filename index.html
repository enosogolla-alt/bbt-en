Internet Terminology
Reference Guide

A comprehensive breakdown of fundamental Internet and Web Technology terms. Select any term from the sidebar or click a card below to explore its role in Computer and Internet Technology.

01
World Wide Web
The global information system built on hyperlinks and HTTP.
02
TCP/IP
The foundational communication protocols of the Internet.
03
Web Browsers
Software that retrieves and renders web pages for users.
04
Web Servers
Systems that store and deliver web content on request.
05
Uniform Resource Locators
Addresses used to locate resources on the Internet.
06
Domain Name Server
Translates human-readable domains into IP addresses.
07
HTTP
Protocol governing data transfer between browsers and servers.
08
Intranet
A private network accessible only within an organisation.
09
Extranet
A controlled extension of an intranet to external partners.
10
Multitier Architecture
Layered design separating presentation, logic, and data.
11
File Transfer Protocol
Standard protocol for transferring files over a network.
12
HTML
The markup language used to structure web page content.
13
Web 1.0
The static, read-only era of the early web (1991–2004).
14
Web 2.0
The interactive, social and user-generated content era.
15
Web 3.0
The semantic, decentralised and intelligent web.
16
Web 4.0
The symbiotic, AI-driven and immersive web of the future.
