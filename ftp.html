File Transfer Protocol
Abbreviated: FTP  •  Secure version: SFTP / FTPS  •  Ports: 20 & 21

File Transfer Protocol is a standard network protocol used to transfer files between a client and a server over a TCP/IP network. It is one of the oldest Internet protocols still in use today, designed specifically for moving large files reliably across networks — from uploading website files to a web server to downloading software from a remote system.

◆ FTP uses two separate channels — a control channel for commands and a data channel for file transfers between client and server
How FTP Works
01
Client connects to the FTP server

The FTP client software connects to the server on Port 21 — the control channel — and the user authenticates with a username and password.

02
Commands are exchanged

The client sends commands through the control channel — such as listing files, changing directories, or initiating a file transfer.

03
Data channel opens on Port 20

When a file transfer begins, a separate data channel opens on Port 20 to handle the actual movement of file data between client and server.

04
File is transferred and connection closes

Once the transfer is complete, the data channel closes while the control channel remains open for further commands or a clean disconnect.

FTP Variants
FTP
Standard, unencrypted file transfer. Fast but not secure for sensitive data.
FTPS
FTP with SSL/TLS encryption added for secure file transfers over the network.
SFTP
SSH File Transfer Protocol — a completely separate, fully encrypted protocol for secure transfers.
Role in Computer & Internet Technology

FTP was one of the earliest tools that made the Internet practically useful — allowing files to be shared between computers across the world long before the Web existed. Today it remains widely used by web developers to upload website files to hosting servers, by organisations to distribute large files internally, and by software providers to manage file repositories.

📄
Age of FTP: FTP was first specified in 1971 — making it over 50 years old and one of the longest-surviving protocols in Internet history, predating even the World Wide Web by two decades.
